# HFI Financial Calculators – GitHub Pages Preview

## Publish as a live preview
1. Create a **Public** GitHub repository.
2. Extract this ZIP on your computer.
3. Upload the **contents of this folder** to the repository root (do not upload the ZIP itself).
4. Confirm `index.html` is visible on the repository's main page beside the `css`, `js`, and `assets` folders.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/(root)`, then Save.
8. Wait for GitHub Pages to publish. The public URL appears in Settings → Pages.

This is a static preview for testing the calculator interface and JavaScript calculations. It does not install or test the WordPress plugin. Google Fonts requires an internet connection. Review all formulas and compliance wording before production use.
