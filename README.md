# Hum Fauji Initiatives – Financial Calculators

Responsive front-end website containing nine interactive financial calculators, restyled using the HFI homepage screenshot supplied by the user as the visual reference.

## Theme reference
- Poppins typography throughout.
- White navigation header with HFI logo image crop from the supplied screenshot.
- Saffron/orange top strip and highlights.
- Deep navy-blue headings, buttons and navigation.
- Light grey-to-warm-cream hero background and clean white content panels.
- Responsive layout for desktop, tablet and mobile.

The logo included in `assets/` is a crop from the supplied website screenshot, not the original vector/high-resolution brand asset. Replace it with HFI's approved logo file before production. Colours and dimensions are visually sampled/approximated from the screenshot, not official brand tokens. The screenshot does not provide the full live-site page, so this is a close visual adaptation rather than a pixel-perfect clone.

## Run locally
Extract the ZIP and open `index.html` in a modern browser. Google Fonts requires an internet connection; Segoe UI/Arial are fallbacks. No build step or external JavaScript dependency is required.

## Production integration
A developer can deploy this folder as a route such as `/calculators/` or migrate it into the existing website template. Replace the screenshot-cropped logo with the approved logo asset and confirm exact brand colours, navigation destinations and contact links with HFI before launch.

## Important calculation notes
These calculators provide illustrative estimates, not financial, tax, insurance or legal advice. SIP and market-linked returns are not guaranteed. The SIP formula assumes monthly investments at the beginning of each month. Step-up SIP raises contributions annually. Retirement and HLV are simplified models and omit important personal circumstances unless entered. The tax estimator uses a user-entered effective tax rate; it does not implement official Indian tax slabs, rebates, deductions, surcharge or special-rate income. Have HFI's financial-planning, tax and compliance teams validate assumptions and outputs before production use. The starter does not collect or transmit user data.
